Unit 3: Identifying and Assessing Risk

The unit covers external risk, the evolving risk landscapes and maintenance and monitoring risk.

Emerging AI risks in information security

The rise of AI has enabled non-technical people to become "vibe coders" and create their own companies built from no-code development sites such as Lovable or from an agent in their IDE. People are now also able to use AI agents such as OpenClaw and integrate them into their systems to handle their daily tasks. Introducing more technology to people unaware of security fundamentals may, however, pose a risk.

According to the General Data Protection Regulation (GDPR), the responsibility of people's personal data falls on the data controller (Regulation (EU) 2016/679 Art. 5(2), 2016), meaning that the business owner is held accountable for the protection of the data. The protection of this, however, is not a given as users without the technical knowledge in how to handle data securely fail to do so. The emergence of AI autonomy has shifted the responsibility of data handling from subject matter experts to non-technical people, creating a gap in ensuring the security of personal data. Veracode found that 45% of code samples included OWASP Top 10 vulnerabilities (Wessling, 2025). Furthermore, row-level security was not enabled by default on Supabase databases on Lovable projects, which left data exposed (National Vulnerability Database, 2025).

When setting up an autonomous agent, the users can allow more access to the agent than needed. OpenClaw was by default listening on all 0.0.0.0 network interfaces (Vavra, 2026), so to close off access and connect only via the users’ local computer, the user had to configure the settings. The failure to secure the agent exposed 42,900 IP addresses with control panels set to full access (Vavra, 2026), meaning that adversaries could reach the control panel of the users’ AI system if able to bypass authentication.

Due to the availability of AI tools and autonomous agents, technical tools are no longer only accessible to specialists. Sites are created with vulnerabilities or AI systems set to permissive default security settings, often without the people using them being aware. As a result, the risk landscape expands to include more websites and entry points which now belong to non-technical people.
